### Product description

MYXCROW is a secure escrow platform designed for buyers and sellers in Ghana. It facilitates GHS-denominated transactions with wallet management, escrow funding and release, delivery confirmation, dispute resolution, KYC verification (Ghana Card), and an administrative dashboard. The system comprises:

| Component | Technology |
|-----------|------------|
| Web application | Next.js 14 (TypeScript) |
| Backend API | NestJS 10 (TypeScript) |
| Database | PostgreSQL 15 (30 tables) |
| Payments | Paystack integration |
| Identity | Smile Identity (Ghana Card KYC) |

### Submission contents (two identical pen drives)

1. **Executable** — Docker Compose configuration and run instructions (`01-executable/`)

3. **Database schema** — Prisma schema, SQL migrations, and data dictionary (`03-database-schema/`)
4. **Screen recording** — Demonstration video of application functionality (`04-screen-recording/MYXCROW-demo.mp4`)
5. **Company documents** — Ghana Cards of developers and Certificate of Incorporation (`05-company-documents/`)
